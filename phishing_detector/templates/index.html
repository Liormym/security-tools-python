How to export an email as plain text
1
Gmail — Show Original
Open the email → click the ⋮ three dots menu (top right of the email) → select "Show original". A new tab opens with the full raw email. Select all → copy → paste here.
⋮ menu → Show original → Select All (Cmd/Ctrl+A) → Copy → Paste
2
Outlook — Save as .eml
Open the email → File → Save As → choose type .eml → open the file with Notepad or TextEdit → copy all the content → paste here.
File → Save As → .eml → open with Notepad → Select All → Copy → Paste
3
Apple Mail — Raw Source
Open the email → menu bar → View → Message → Raw Source (shortcut: ⌥⌘U) → select all → copy → paste here.
View → Message → Raw Source (⌥⌘U) → Select All → Copy → Paste
4
Quick manual format
Just want to test something quickly? Type it in this format:
From: sender@example.com To: you@example.com Reply-To: other@gmail.com Subject: Your subject here Email body text here... http://any-links.com
💡 Tip: The more header lines you include (From, Reply-To, Subject), the more checks the detector can run. At minimum, paste the email body — it will still scan for suspicious links and urgent language.
