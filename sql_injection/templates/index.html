How SQL Injection Works

⚠️ Vulnerable — string concatenation The user input is glued directly into the SQL string. An attacker can break out of the string with a quote and inject arbitrary SQL logic.
WHERE username = '' OR '1'='1' AND password = '' OR '1'='1'
The condition becomes always-true → login succeeds without valid credentials.
✅ Secure — parameterised query A ? placeholder keeps SQL structure and data completely separate. The database driver escapes the input before it ever touches the query — injection is structurally impossible.
WHERE username = ? AND password = ?
params: ("' OR '1'='1", "' OR '1'='1")
The injected string is treated as a literal value → login fails correctly.
